# example/assets 에 넣을 파일

예시 영상(index.html)이 쓰는 파일 목록이에요. 개인 사진과 영상은 빼고 나눠 드려요. 같은 이름으로 내 파일을 넣거나, Claude에게 "내 파일로 바꿔줘"라고 하면 돼요.

| 파일 | 쓰이는 장면 | 바꿀 것 |
|---|---|---|
| a2z-8.woff2, a2z-5.woff2 | 모든 글자 | 에이투지체(무료 글꼴)를 직접 받아서 넣어요. 다른 글꼴을 써도 돼요 |
| inter.woff2 | 영문 보조 | Inter(무료) |
| nyc_bw.jpg | 기본 배경 | 내 도시나 장소의 흑백 사진 |
| nyc_loft.jpg | 강사 소개 배경 | 실내 공간 사진 |
| ryan.jpg, hamlog.jpg | 강사 카드 | 강사 얼굴 사진(정사각형에 가까운 것) |
| saran_poster.jpg, saran1.mp4, bg_saran.mp4 | 강사 대표작 | 내 대표작 포스터와 영상 |
| char3d.mp4, duo_breakout.mp4 | 3D 캐릭터 장면 | 힉스필드 등으로 만든 캐릭터 영상(없으면 빼도 돼요) |
| bg_screens.mp4, bg_climax.mp4, drama1.mp4 | 결과물 장면 배경 | 실제 작업 화면이나 결과물 영상 |
| ig_report.jpg | 자동화 결과 예시 | 실제 리포트·결과 화면 캡처 |
| venue1~3.jpg | 장소 장면 | 행사 장소 사진 |
| claude-color.svg | 터미널 창 아이콘 | 그대로 두거나 빼요 |
