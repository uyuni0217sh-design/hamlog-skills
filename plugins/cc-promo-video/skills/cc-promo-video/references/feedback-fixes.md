# 자주 나온 피드백 → 고친 방법

뉴욕 워크숍 영상(v1~v26)을 만들며 실제로 나온 피드백과 적용한 해결책이에요. 비슷한 말이 나오면 이 표대로 바로 고쳐요.

| 피드백 | 고친 방법 |
|---|---|
| 글씨가 작아요 | 화면을 9:16·16:9에서 4:3(1440×1080)으로 바꾸고 모든 글자를 키워요. 자막 50px, 제목 92px |
| 이미지가 꾸민 것 같아요 | 그린 일러스트를 빼고 실제 사진·결과물 화면으로 바꿔요 |
| 뉴욕 느낌이 안 나요 | 미드저니 프롬프트를 드려서 흑백 스카이라인 이미지를 받아 배경으로(채도 0, 대비 1.5, 밝기 0.9) |
| 주황색이 촌스러워요 | 강조색을 앰버 #FFB547로. 라벨 알약도 같은 색 14% 면 + 35% 테두리 |
| 배경이 밝아 글자가 떠 보여요 | 자막 아래 380px 검정 그라데이션(82% → 40% 지점 55% → 0), 왼쪽 글 덩어리 뒤 `veil-left` |
| 컷 바뀔 때 빈 화면이 끼어요 | 장면 사이 0.12초 교차, 다음 장면 요소를 0.35초 먼저 들여보내요. 빈 프레임은 스냅샷으로 0.1초 간격 확인 |
| 날짜가 있으면 좋겠어요 | 위쪽 태그 줄 「A × B · 도시 · 날짜」, 날짜만 강조색 |
| 남은 분량을 보여주세요 | 오른쪽 위 200×6px 진행 바. 숫자 타이머는 빼요 |
| 숫자가 붙어서 헷갈려요(2 12) | 숫자 사이 간격을 벌리고 단위를 작게 붙여요(2일 12시간) |
| 얼굴이 밋밋하게 나와요 | 등장을 스케일 바운스(back.out)로 |
| 자막을 읽기 쉽게 | 뜻이 끊기는 곳에서 직접 `<br>`로 두 줄 |
| 실명이 보여요 | 활동명만 남기고 파일명·자막·이미지 속 글자까지 확인 |
| 비행기가 안 보여요 | 검정 배경 위 요소는 흰색으로 |
| 인트로를 앞에 붙이고 싶어요 | 본편 앞부분을 잘라내고 0.7초 xfade 디졸브, 인트로 구간 자막 PNG를 페이드로 얹어요 |
| 인트로에서 넘어갈 때 컷이 튀어요 | 디졸브 지점을 내레이션 쉼에 맞추고 본편 시작점을 장면 첫 프레임이 완성된 시점으로 |
| 속삭이듯 한 줄 넣어줘 | 해당 문장만 따로 녹음, 영상은 직전 장면 정지 프레임 → 검정 페이드 → 가운데 자막, 끝나면 다음 장면이 검정에서 0.4초 페이드 인 |
| 자막이 흔들리게 | 떨림·RGB 잔상은 어지럽다는 반응. 잔잔한 물결(`scripts/whisper_wave.py`, 7px·1.8초)로 |
| 숫자가 촤라라락 올라가게 | GSAP 카운터 객체 tween + onUpdate로 글자 갱신(`scripts/patch_countup_example.py`), 도착 시 1.08배 톡 |
| 0이 스르륵 사라지게 | 0만 x 60px, blur 14px, opacity 0, 0.7초 power2.inOut |
| 너무 빨라요(1.2배속) | 원래 속도로 되돌려요 |
| 음악이 안 어울려요 | 후보 두세 곡을 같은 믹스로 만들어 비교. 결국 처음 곡이 맞는 경우가 많았어요 |
