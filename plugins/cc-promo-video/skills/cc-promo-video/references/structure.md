# 영상 구성

88초를 13개 장면으로 나눴어요. 흐름은 "질문 → 우리가 간다 → 누가 → 뭘 할 수 있게 되나 → 반전 → 걱정 덜기 → 어디서 → 숫자 훅 → 할 일"이에요. 시간은 최종본 v26 기준이에요.

## 장면 순서

| 시간 | 장면 | 하는 일 |
|---|---|---|
| 0–9초 | 인트로 | 3D 캐릭터가 뉴욕 거리에서 「혹시 아직도 AI를 채팅으로만 쓰고 계신가요?」라고 물어요. 첫 3초에 질문을 던져서 넘기지 않게 해요. |
| 9–14초 | 훅 | 같은 질문을 큰 제목으로 다시 보여주고, 채팅창과 3시간째 편집 중인 타임라인으로 "지금 내 모습"을 보여줘요. |
| 14–21초 | 한국에서 찾아갑니다 | 서울 → 뉴욕 비행 경로 위로 두 강사가 차례로 나와요. "뉴욕 한인분들을 위해" 직접 간다는 게 핵심이에요. |
| 21–29초 | 2일 12시간 | 「이런 기회, 흔치 않아요」. 바이브 코딩과 AI 영상을 한 번에 배운다는 걸 두 캐릭터가 화면 밖으로 뛰어나오며 보여줘요. |
| 29–32초 | 툴 강의 아님 | 검정 바탕에 짧게 한 줄. 도구 사용법이 아니라 일하는 방식을 바꾸는 수업이라고 선을 그어요. |
| 32–40초 | 라이언 소개 | 이름, 한 줄 역할, 이력 칩(KAIST, 네이버, 개발 15년). |
| 40–45초 | 라이언에게 배우면 | 「매주 붙잡고 있던 반복 업무, 이제 말 한마디면 AI가 대신 끝내요」. 이력 바로 뒤에 결과를 붙여요. |
| 45–55초 | 햄로그 소개 | 「사란」 포스터와 예고편 장면 위로 이력 칩, 「뉴욕에서 4관왕」. |
| 55–61초 | 햄로그에게 배우면 | 「내 상품을 소개하는 AI 모델 릴스, 실사 같은 시네마틱 영상까지 직접 만들게 돼요」. |
| 61–67초 | 반전 | 화면이 꺼지고 속삭임: 「사실, 이 영상도 이 목소리도 전부 AI가 만들었어요」. 방금 본 영상 자체가 증거가 돼요. |
| 67–73초 | 설치부터 같이 | 「처음이어도 괜찮아요」. 사전 줌 세미나에서 Claude Code 설치부터 도와준다고 걱정을 덜어줘요. |
| 73–77초 | 장소 | 첼시 Gallery AP SPACE 실제 사진과 주소. |
| 77–83초 | 숫자 훅 | 2일 → 20년 → 2주 뒤. 숫자 2 하나로 투자, 효과, 마감을 한 번에 말해요. |
| 83–88초 | CTA | 날짜·장소·두 강사 얼굴과 「자세한 내용은 댓글의 Luma 링크를 참고해 주세요!」 |

## 이렇게 구성한 이유

- **질문으로 시작해요.** "AI 워크숍입니다"로 시작하면 넘겨요. 「아직도 채팅으로만?」은 보는 사람이 자기 얘기인지 바로 판단하게 해요.
- **강사 소개 바로 뒤에 "그래서 뭘 할 수 있게 되나"를 붙여요.** 이력만 나열하면 자랑으로 끝나요. 라이언 → 반복 업무 자동화, 햄로그 → 내 상품 영상처럼 듣는 사람이 얻는 것으로 이어요.
- **증거는 영상 자체예요.** 속삭임 장면이 "이 영상도 AI로 만들었다"고 밝히면서, 앞에서 본 모든 화면이 수업 결과물의 예시가 돼요. 이 장면은 결과 소개 바로 뒤, 걱정 덜기 바로 앞에 둬요.
- **걱정은 끝에서 덜어줘요.** "어렵겠다"는 생각이 들 즈음 「처음이어도 괜찮아요」와 설치 지원이 나와요.
- **마지막은 숫자 하나로 기억하게 해요.** 2일, 20년, 2주가 다 2로 시작하는 걸 이용해 숫자 2를 화면에 계속 두고 뒤만 바꿔요.
- **끝은 할 일 한 줄이에요.** 링크가 어디 있는지만 말하고 끝내요.

## 만들 때 팁

1. **대본을 장면 표로 먼저 써요.** 장면마다 내레이션 한 줄과 화면 제목 한 줄을 따로 써요. 화면 제목은 내레이션보다 짧게 줄여요(「바이브 코딩과 AI 영상을 한 번에 배울 기회는 흔치 않아요」 → 「이런 기회, 흔치 않아요」).
2. **장면 하나에 말 하나예요.** 숫자를 말하면 큰 숫자, 이동을 말하면 지도·비행기, 사람을 말하면 얼굴과 칩을 보여줘요.
3. **장면 길이는 내레이션이 정해요.** 목소리를 먼저 녹음하고, 문장 끝나는 시간에 맞춰 장면을 자르면 컷이 어색하지 않아요.
4. **배경은 장면 뜻에 맞춰 바꿔요.** 인물 소개는 로프트, 사란은 예고편 첫 장면, 결과는 실제 작업 영상, 핵심 문장은 검정이에요. 같은 배경을 오래 두면 지루해져요.
5. **반전은 한 번만 넣어요.** 속삭임처럼 톤이 확 바뀌는 장면은 영상 2/3 지점에 한 번이면 충분해요.
6. **다 만든 뒤 처음부터 끝까지 보면서 거슬리는 것만 말해요.** "컷이 튀어", "글자가 떠 있어", "어지러워" 같은 말이 마지막 완성도를 만들었어요.
