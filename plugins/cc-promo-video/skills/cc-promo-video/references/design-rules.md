라이언 × 햄로그 뉴욕 워크숍(2026.11.21–22, 첼시 Gallery AP SPACE) 소개 영상의 디자인 규칙이에요. 최종본 v26(1440×1080, 4:3, 88초)에 실제로 쓴 값만 옮겼어요. 모든 크기는 1440×1080 화면 한 장 기준이에요.

어떤 말을 쳐서 이 영상이 나왔는지는 「이렇게 만들었어요」 장에 따로 정리했어요.

## 한눈에

- 화면은 4:3(1440×1080)이에요. 처음엔 9:16, 16:9로 만들었다가 글자를 키우려고 4:3으로 바꿨어요. 폰에서 글자가 크게 보여요.
- 바탕은 어두운 톤 하나예요. 흑백 뉴욕 스카이라인 사진 위에 검정 막(`veil-left`, `sub-shade`)을 깔아요. 장면에 따라 검정 바탕(`ground`)만 쓰기도 해요.
- 강조색은 앰버 `accent` 하나예요. 주황(#FF6A1A)으로 시작했다가 더 고급스러운 톤을 위해 앰버로 바꿨어요.
- 글꼴은 에이투지체(`a2z`) 한 가족이에요. 제목·숫자 800, 자막 500이에요.
- 자막은 항상 화면 아래 가운데, 흰색 50px 두 줄 이내예요.

## 말투

- 내레이션과 자막은 해요체예요. 「혹시 아직도 AI를 채팅으로만 쓰고 계신가요?」로 묻고 시작해요.
- 화면 제목은 내레이션보다 짧게 끊어요. 내레이션 「바이브 코딩과 AI 영상을 한 번에 배울 기회는 흔치 않아요」 → 제목 「이런 기회, 흔치 않아요」.
- 강사 이름은 활동명만 써요: 라이언, 햄로그. 실명은 쓰지 않아요.
- 숫자는 단위와 같이 크게 보여요: 2일 12시간, 4관왕, 2,900명.
- 마지막은 할 일 한 줄로 닫아요: 「자세한 내용은 댓글의 Luma 링크를 참고해 주세요!」

## 색

| 쓰는 곳 | 토큰 |
|---|---|
| 검정 장면 바탕 | `ground` |
| 제목, 자막, 이름 | `ink` |
| 설명 줄, 작은 라벨 | `ink-muted` |
| 위쪽 태그 줄 | `tag` |
| 강조 글자, 큰 숫자, 날짜 | `accent` |
| 라벨 알약 면과 테두리 | `accent-soft`, `accent-line` |
| 채팅창·카드 면 | `glass` |
| 이력 칩 면 | `chip` |
| 카드·칩 테두리 | `line` |
| 사진 왼쪽 어둡게 | `veil-left` |
| 자막 뒤 아래 그라데이션 | `sub-shade` |
| 진행 바 바탕 | `track` |

- 사진 배경은 흑백(채도 0, 대비 1.5, 밝기 0.9)으로 써요. 색이 들어간 사진은 카드 안의 사진(인물, 포스터)만이에요.
- 자막 뒤에는 항상 `sub-shade` 그라데이션을 깔아요(아래 380px, 맨 아래 82% → 40% 지점 55% → 0). 밝은 배경에서 글자가 떠 보이지 않게 넣었어요.
- 한 장면에 `accent`는 한 군데만 크게 써요. 제목 안의 한 단어(「채팅으로만」, 「찾아갑니다」), 또는 큰 숫자 하나예요.

## 글꼴

- 모든 글자가 `a2z`(에이투지체)예요. 명조, 이탤릭, 손글씨는 쓰지 않아요.
- 스타일: 큰 숫자 `number-giant`, 장면 제목 `headline`, 인물 이름 `name`, 속삭임 자막 `whisper`, 자막 `subtitle`, 이력 칩 `chip`, 라벨 알약 `kick`, 위쪽 태그 `tag`.
- 화면 위 글자에는 그림자 `text-shadow`를 줘요. 밝은 사진 위에서도 읽혀요.

## 크기와 여백

- 왼쪽 글 덩어리는 화면 왼쪽에서 `frame-pad`(80px) 안쪽에 둬요. 오른쪽 절반에는 카드나 영상을 둬요.
- 자막은 좌우 `sub-inset`(60px), 위에서 912px에 놓고 줄 높이 66px이에요.
- 칩끼리 `gap-10`, 라벨과 제목 사이 `gap-28`이에요.
- 모서리: 카드 `radius-card`(26px), 칩 `radius-chip`(18px), 라벨 알약 `radius-pill`, 진행 바 `radius-bar`(3px)예요.

## 장면 장치

- **위쪽 태그 줄**: 모든 장면 왼쪽 위에 「라이언 × 햄로그 · NEW YORK · 2026.11.21–22」. 날짜만 `accent`예요. 오른쪽 위에는 200px 진행 바가 88초 동안 차요. 숫자 타이머는 빼고 바만 남겼어요.
- **자막**: 뜻이 끊기는 곳에서 직접 두 줄로 나눠요. 「AI 영상은 한 번도 안 만들어 봤거나, / 편집을 하나하나 직접 하고 계신 분」.
- **큰 숫자**: 「2일 → 20년 → 2주 뒤」 한 장면에서 숫자 2를 계속 두고, 2가 2, 3, 6, 12를 거쳐 20까지 올라갔다가, 0만 오른쪽으로 흐려지며 사라져 2주 뒤가 돼요.
- **인물 카드**: 사진은 둥근 카드에 넣고 등장할 때 스케일 바운스로 튀어나와요.
- **속삭임 장면**: 화면이 검게 페이드되고, 가운데에 두 줄 자막이 잔잔한 물결로 오르내려요. "AI"만 `accent`예요.

## 움직임

- 장면 사이는 0.12초 교차로 넘어가요. 빈 화면이 끼지 않게 다음 장면 요소가 0.35초 먼저 들어와요.
- 인트로 클립에서 본편으로는 0.7초 디졸브예요.
- 흔들림은 쓰지 않아요. 덜덜 떨리는 자막은 어지러워 보여서 뺐고, 물결(글자마다 7px, 1.8초 주기)만 남겼어요.

## 소리

- 내레이션은 햄로그 본인 목소리 클론(일레븐랩스 v4)이에요. 속삭임 한 줄만 원래 속도로 따로 녹음했어요.
- 음악은 「Guest House」 한 곡을 처음부터 끝까지 깔고, 목소리가 나올 때 자동으로 줄어들어요. 끝 3.5초는 페이드 아웃이에요.
- 효과음은 넣지 않아요.

## 이미지

- 아이콘 세트와 로고 파일은 없어요. 이름은 `a2z`로 써요.
- 사진은 실제 강사 사진, 실제 갤러리 사진, 영화 「사란」 포스터와 예고편 장면을 써요. 3D 캐릭터 장면과 인트로 장면만 AI로 만든 영상이에요.
- Frames 그룹에 최종본의 주요 장면 9장을 넣었어요.
